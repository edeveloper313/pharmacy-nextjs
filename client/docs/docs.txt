# Voice

INVOICE / BILLING

The following fields and options are required for invoice generation:

1.  Company Information
      - During invoice/report generation, the Company Name, Address, Phone
        Number, and Owner Name should appear automatically.
      - Company information should be entered only once.
      - When generating a report, the user should only need to select the
        company.
2.  Per-Piece Quantity
      - The system should support quantity calculations by individual pieces.
      - Example: 10 tablets per strip/card; 2 strips/cards per box; 60 pieces
        per box; 3,000 pieces in total based on the number of boxes/cartons.
3.  Total Quantity
      - The system should also support quantity calculations by box/carton.
      - Example: 30 boxes per carton × 50 cartons = 1,500 boxes.
4.  MFG (Manufacturing Date)
5.  EXP (Expiry Date)
6.  TP (Trade Price) — entered during Trade Entry.
7.  MRP (Maximum Retail Price) — entered during Trade Entry.
8.  Rate / Discount
      - If the Rate is entered, the Discount should be calculated automatically.
      - If the Discount is entered, the Rate should be calculated automatically.
9.  Date
10. Invoice Number
11. Batch Number
12. Generic (Optional)
13. Generic-Wise Invoice (Optional)
      - The system should allow invoices to be generated by Generic only, when
        required.

INVOICE PRINTING OPTIONS

The following options should be available when generating/printing an invoice:

1.  Each-Piece Invoice
2.  Batch-Wise Invoice
3.  TP (Trade Price)
4.  Print Button
5.  DC (Delivery Challan) Button
